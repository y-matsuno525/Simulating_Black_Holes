# Simulating Black Holes

ブラックホール時空を模した 1 次元格子模型について、BdG ハミルトニアン、Bogoliubov 変換、時間発展、密度・相関量の可視化を行うための Python スクリプトと、その出力データをまとめたリポジトリです。

## フォルダ構成

| パス | 説明 |
| --- | --- |
| `data/` | 数値計算で得られた CSV データを保存するフォルダです。直下には代表的な出力があり、サブフォルダには条件別の出力が保存されています。 |
| `data/b_0/`, `data/b_01/` | `b` 系の条件で計算した出力データです。フォルダ名の `0`、`01` は条件やパラメータの違いを表します。 |
| `data/b_0_r/`, `data/b_01_r/` | `b` 系条件の別バージョンまたは反転・右側条件に対応する出力データです。 |
| `data/nb_0/`, `data/nb_01/` | `nb` 系の条件で計算した出力データです。 |
| `data/nb_0_r/`, `data/nb_01_r/` | `nb` 系条件の別バージョンまたは反転・右側条件に対応する出力データです。 |
| `figure/` | 計算結果を可視化した PNG 画像と GIF アニメーションを保存するフォルダです。 |
| `my_func/` | BdG 行列生成、演算子計算、固有ベクトル整列、描画、チェック関数などをまとめた補助モジュールです。 |
| `__pycache__/`, `my_func/__pycache__/` | Python が自動生成するキャッシュです。通常は編集不要です。 |
| `.git/` | Git の管理情報です。通常は直接編集しません。 |

## 主要スクリプト

| ファイル | 説明 |
| --- | --- |
| `painleve_geo.py` | Painleve 型の背景で BdG ハミルトニアンを作り、時間発展、密度・相関量の計算、測地線付きの図の保存を行う中心的なスクリプトです。 |
| `painleve_sg.py` | 表面重力や波束幅に関係する量を追跡しながら、`H_p`、`H_m`、`H_pm`、`c_dag_c` などを計算・描画するスクリプトです。 |
| `painleve_sg2.py` | `painleve_sg.py` の発展版です。`x_ave.txt`、`H_m_sigmas.txt` の保存や GIF アニメーション生成処理も含みます。 |
| `painleve_b.py` | beta 関数の条件を変えた Painleve 系の計算スクリプトです。CSV 保存用の関数も含みます。 |
| `painleve_p.py` | 位置依存の `p(j)` を導入した BdG ハミルトニアンと時間発展を扱うスクリプトです。 |
| `painleve_ini.py` | 初期条件や beta 関数の形を試すための Painleve 系スクリプトです。 |
| `painleve_mode.py` | 固有モード関数を取り出して `figure/mode_function_...png` として保存するスクリプトです。 |
| `painleve_share.py` | beta が 0 の共有・基準ケースに近い設定で、BdG 行列、固有値、時間発展を確認するスクリプトです。 |
| `painleve2.py` | Painleve 系計算の旧版または実験版と思われるスクリプトです。 |
| `painleve_k.py` | 運動量空間または k モードに関係する演算子・状態ベクトルを扱う実験用スクリプトです。 |
| `logL.py` | 格子サイズやスケールに関する解析、図保存、アニメーション保存を含む大きめの解析スクリプトです。 |
| `geo.py` | null geodesic を常微分方程式として解き、`geodesic.dat` を生成するスクリプトです。 |
| `surface_gravity.py` | `p=0_H_m_sigmas.txt` を読み込み、指数関数フィットと解析予測との比較プロットを行うスクリプトです。 |
| `op_test.py` | BdG ハミルトニアンや演算子の構成をテストするためのスクリプトです。 |
| `test.py`, `test2.py`, `test3.py` | 固有値計算、時間発展、描画などを小さく検証するためのテスト・試作用スクリプトです。 |

## 補助モジュール

| ファイル | 説明 |
| --- | --- |
| `my_func/__init__.py` | `my_func` を Python パッケージとして扱うための空ファイルです。 |
| `my_func/beta.py` | beta 関数を定義するモジュールです。現在は冒頭で `0` を返すため、以降の条件分岐は無効になっています。 |
| `my_func/my_check.py` | エルミート性、ユニタリ性を確認する関数を定義します。 |
| `my_func/my_operator.py` | BdG 行列、時間発展演算子、真空期待値、`H_p`、`H_m`、`H_pm`、相関量などを生成する関数群です。 |
| `my_func/my_plot.py` | 密度・相関量の時間発展を PNG や GIF として保存する描画関数群です。測地線データの重ね描きにも対応しています。 |
| `my_func/fix_eigenvectors.py` | 固有値・固有ベクトルの並べ替え、位相の補正を行う関数を定義します。 |
| `my_func/geodesic.dat` | 補助モジュール側で参照する測地線データです。 |

## データファイル

| ファイル | 説明 |
| --- | --- |
| `H_p_0.csv`, `H_m_0.csv`, `H_pm_0.csv` | 各量の初期時刻または基準時刻における値を保存した CSV です。 |
| `H_p_val.csv`, `H_m_val.csv`, `H_pm_val.csv` | `H_p`、`H_m`、`H_pm` の時間発展データを保存した CSV です。 |
| `c_dag_c_val.csv` | 数演算子または密度に対応する `c^\dagger c` の時間発展データです。 |
| `cdc_0.csv` | `c^\dagger c` の初期値または基準値です。 |
| `cj1_cj_0.csv` | 隣接サイト相関 `c_{j+1} c_j` の初期値または基準値です。 |
| `cj1_dag_cj_0.csv` | 隣接サイト相関 `c_{j+1}^\dagger c_j` の初期値または基準値です。 |
| `geodesic.dat`, `left_geodesic.dat`, `!geodesic.dat`, `!!geodesic.dat` | 測地線を表すデータファイルです。図に重ね描きする補助線として使われます。 |
| `p=0_H_m_sigmas.txt`, `p=1_H_m_sigmas.txt` | `H_m` に関する幅や標準偏差の時間変化を保存したテキストデータです。 |
| `x_ave.txt` | 位置の平均値など、時間ごとの代表位置を保存したテキストデータです。 |

`data/` 以下の各サブフォルダにも、上記と同名の CSV 群が保存されています。サブフォルダごとに計算条件が異なるため、条件別の結果を比較するためのデータとして扱います。

## 実行に必要な主なライブラリ

このリポジトリのスクリプトは主に以下の Python ライブラリを使います。

- `numpy`
- `scipy`
- `matplotlib`

アニメーション GIF を保存する処理では、`matplotlib.animation.PillowWriter` を使うため、環境によっては `Pillow` も必要です。

## 注意

- 多くのスクリプトは実行すると `figure/` やルート直下の CSV・TXT ファイルを上書きする可能性があります。
- コメントの一部に文字化けがありますが、コード本体は Python として読める状態です。
- `__pycache__/` は自動生成物なので、README 上では保守対象外として扱っています。
